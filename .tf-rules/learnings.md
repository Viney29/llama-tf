[chat] Store collection handles for the tabbed carousel are `kids`, `for-adults`, and `bundles` — NOT `adults` or `bundle-save` (those don't exist). When a collection-referencing setting renders empty, verify the handle against the live store (`/collections.json`) before assuming a code bug.
[chat] A `collection` setting that points to a non-existent handle fails silently in Liquid (`collection != blank` is false) — no error, just an empty render. Always confirm handles exist on the store, not just that the Liquid logic is correct.
[chat] Horizon's `body` is a flex column with NO `overflow-x` guard — the theme relies on the `.section` grid to contain everything. A horizontal-scroll carousel/track (`overflow-x: auto`) clips visually but its LAYOUT overflow leaks up through `overflow: visible` ancestors into the document scroll region, causing page-wide horizontal scroll with blank space on the right. Fix: add `overflow-x: clip` to the section root (full-viewport-width box) so it can't propagate. `overflow-x: clip` keeps the vertical axis visible (won't clip absolutely-positioned badges/arrows that sit within the box) and doesn't disable the inner track's own scroll.
[chat] To preview an UNPUBLISHED Horizon dev theme in a headless browser, append `&_fd=0&pb=0` to the preview URL (`...myshopify.com/?preview_theme_id=ID&_fd=0&pb=0`). Without `_fd=0`, Shopify redirects the apex to the primary/custom domain and drops the preview param, so you end up measuring the LIVE published theme instead. Playwright + system Chrome (`channel:'chrome'`) is available; import playwright by absolute path from the global node_modules (ESM ignores NODE_PATH).
[chat] Debugging "horizontal scroll throughout the page": measure `document.documentElement.scrollWidth` vs `innerWidth`, then find the offending top-level section via `el.scrollWidth - el.clientWidth > 1` on each `.shopify-section`. Note `getBoundingClientRect()` returns a slide's full position even when correctly scrolled out of an `overflow:auto` track — so a slide's rect extending past the viewport is NOT proof the track fails to clip; check the track's own `clientWidth` (box) instead.
